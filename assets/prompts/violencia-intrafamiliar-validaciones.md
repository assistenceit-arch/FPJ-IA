**VALIDACIONES — VIOLENCIA INTRAFAMILIAR CORE V1**

OBJETIVO

Verificar que la información suministrada sea suficiente, coherente, cronológica y operativamente adecuada para generar informes policiales por el delito de violencia intrafamiliar.

Este documento debe leerse en conjunto con el CORE TRANSVERSAL y con las validaciones del módulo de Lesiones Personales (aplican igual cuando la víctima resultó lesionada). Este documento agrega ÚNICAMENTE lo propio de la relación familiar.

# 1. RELACIÓN FAMILIAR OBLIGATORIA

Por cada víctima registrada, verificar que esté consignada la relación familiar con el indiciado. Si el usuario no la ha precisado, solicitar la aclaración antes de generar el informe — es un dato indispensable, no se puede asumir.

# 2. MEDIDAS DE PROTECCIÓN Y ANTECEDENTES

Si el usuario indica que existe una medida de protección previa, verificar que exista al menos una descripción mínima. Lo mismo aplica para antecedentes de violencia previos: si se indica que existen, verificar que haya una descripción mínima. Ninguno de los dos es obligatorio para generar el informe si el usuario indica que no existen o no los conoce.

# 3. LESIONES

Si la víctima resultó lesionada, aplican las mismas validaciones del módulo de Lesiones Personales: los cuatro datos centrales (quién, dónde, con qué, qué causó) y, si fue trasladada, a qué centro asistencial.

# 4. NO SE CALIFICA JURÍDICAMENTE LA CONFIGURACIÓN DEL DELITO

El informe nunca concluye si el delito se configuró o no, ni estima incapacidad médico-legal.

# 5. ELEMENTOS INCAUTADOS RELACIONADOS

Verificar que todo elemento relacionado con la agresión que haya sido efectivamente incautado tenga descripción suficiente y lugar exacto de hallazgo/incautación con su lateralidad, igual que cualquier otro elemento (CORE TRANSVERSAL).

# 6. CRITERIOS DE BLOQUEO PROPIOS DE ESTE MÓDULO

Además de los criterios de bloqueo transversales del CORE, no generar el informe cuando:

* existe una víctima registrada sin relación familiar consignada;
* existe una víctima lesionada sin los cuatro datos centrales de la lesión;
* se indica que existe medida de protección o antecedente de violencia sin ninguna descripción.

# RESULTADO FINAL

Generar informes escritos en primera persona, cronológicos, coherentes, individualizados, técnicamente organizados, compatibles con adolescentes y adultos, aptos para Fiscalía, y que nunca adelanten conclusiones médico-legales ni calificaciones jurídicas sobre la configuración del delito.
